# BluePixel 画布工作流 / Canvas workflows

只提供可编辑的 ComfyUI 画布 JSON，不提供 API 工作流。
Only editable ComfyUI canvas JSON files are included.

1. 推荐先下载 [02_edit_1k_preview.json](02_edit_1k_preview.json)。在 GitHub 文件页点击 **Raw / Download raw file**，或解压 Release ZIP 的 `workflows` 目录。
2. 把下载的本地 `.json` 拖入 ComfyUI 画布，或按 **Ctrl+O** 选择文件。不要把 GitHub 网页另存为 JSON。
3. 选择三个 BluePixel 模型，在 `LoadImage` 上传自己的参考图，然后运行。4K 工作流见 [01_edit_4k_int8_convrot.json](01_edit_4k_int8_convrot.json)。

Download the JSON itself, then drop the local file onto ComfyUI or open it with **Ctrl+O**. Select the three BluePixel models and upload your reference image before running. Start with the 1K preview; use the 4K workflow when ready.
